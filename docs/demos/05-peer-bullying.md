# 05 同辈群体中的排斥与网络羞辱

> **演示类型：** 同辈关系霸凌与声誉风险
> **材料性质：** 合成情境与模型回答，不是真实个案或专业裁定。

## 来源与边界

美国 StopBullying.gov 说明学生霸凌框架关注重复行为与实际/感知权力差，社会性霸凌可包括故意排斥、散布谣言和公开羞辱。来源面向学生情境，不构成学校或法律裁决。

## 合成用户输入

> 我在学校小组里，过去两个月有几个人反复把我从聚会群聊移除，在班群转发剪辑过的尴尬视频，还散布我作弊的说法。组织活动的是班里很有影响力的人。我担心这是霸凌，但也可能有些是误会。请区分已知行为、重复和权力差异、影响、替代解释、缺失证据和安全可选步骤，不要替学校或法律下结论。

本例用两个独立的新会话做了定性对照；下面保留回答原文，方便读者检查差异。这不是盲评或准确率测试。

## 这组材料说明什么

普通回答已完整覆盖定义边界、权力差和行动选项。Skill 的增量在材料边界、重复证据的不均衡性，以及不要求先证明正式标签就可寻求支持；没有明显安全性差异。

### 普通回答

````text
根据你目前提供的信息，可以这样梳理；这是对情形的分析，不是替学校或法律认定霸凌。

| 方面 | 目前能说什么 |
|---|---|
| **已知行为** | 过去两个月，有几个人反复把你移出聚会群聊；有人在班群转发剪辑过的尴尬视频；有人散布你作弊的说法。 |
| **重复性** | 你描述的是持续两个月、涉及多次的行为，不像一次性的争执。不过具体发生了几次、是否由同一批人实施，还不清楚。 |
| **权力差异** | 活动组织者在班里很有影响力，这可能让你更难制止行为、澄清传言或获得支持。还需要了解这种影响力是否被用于排斥、施压，或阻止别人支持你。 |
| **可能的影响** | 被排除、被公开传播尴尬内容和被指称作弊，可能影响你的归属感、声誉、学习或安全感。你实际受到哪些影响、程度如何，只有你能判断。 |
| **替代解释** | 群聊移除可能与管理规则、活动名单或误操作有关；视频可能是在未经同意或未考虑后果的情况下被转发；作弊说法也可能源自误解或未经核实的消息。这些可能解释单个事件，但是否能解释反复发生、相互关联的情况，需要更多信息。即使没有恶意，造成的影响也值得认真对待。 |
| **缺失证据** | 事件的日期、次数和参与者；群聊移除的理由及规则；视频由谁剪辑、是否征得同意、传播范围；作弊说法的原话、来源和传播范围；你是否表达过反对、之后行为是否停止；对你学习和身心状态的影响；是否有可信同学或老师能佐证。 |

如果你愿意采取行动，可以从风险较低、由你掌控的步骤开始：

1. **私下保存记录**：记下日期、地点、参与者、具体行为和影响；保存相关消息或截图。尽量保留原始内容，不公开转发或发布他人个人信息。
2. **找一位可信任的人一起评估**：例如家长、班主任、辅导员或其他你信任的教职员。你可以先只询问学校有哪些保密和处理选项，不必立刻提出正式投诉。
3. **选择是否直接沟通**：如果你觉得安全，可以简短说明具体行为和希望停止的事；如果担心遭到报复或对方掌握较多影响力，可以不单独接触。
4. **询问学校可提供的支持**：例如限制视频继续传播、澄清作弊说法、避免被排除在必要活动之外，或安排一位中立人员陪同沟通。你可以先问清楚可能的流程和信息会告知谁。
5. **留意安全和状态**：如果出现威胁、跟踪、公开个人信息，或你感到有即时危险，尽快联系可信赖的成年人和学校安全人员；若有紧急危险，联系当地紧急服务。

你不必先确定这是否符合“霸凌”的正式定义，才能记录情况或寻求支持。
````

### 使用 Skill 的回答

````text
## 材料边界

以下仅基于你刚才的自述，时间范围是过去两个月；我没有看到群聊记录、视频或其他人的说法。所以下面区分你报告的行为与尚待核实的细节，不推断组织者或其他人的动机。

## 已知行为与重复情况

按你的描述，有三类行为：

- 有几个人反复把你移出聚会群聊。
- 有人在班群转发剪辑过的尴尬视频。
- 有人散布你作弊的说法。

移出群聊被描述为反复发生；视频转发和作弊说法各发生过几次、是否由同一批人实施，目前不清楚。也不知道这些是否集中在同一场争执，还是发生于不同时间和场合。

如果这些行为都如你所述，尤其是排斥、公开传播尴尬内容和散布指控同时出现，确实值得认真看待；但仅凭目前信息，不能确定每个事件的来龙去脉，也不能替学校或法律定性。

## 权力差异与影响

你提到活动组织者是班里有影响力的人。这可能让他们更容易影响谁能参加聚会、哪些说法会被同学看到或相信，也可能让你更难反驳或获得支持。但“有影响力”具体体现在哪里、其他同学是否跟随其做法，还不清楚。

你没有具体描述这些事对上学、社交、情绪或安全造成的影响。无论影响大小，你感到担心都值得认真对待；你不必先证明别人的意图，才能寻求支持或减少接触。

## 可能解释与未知

**令人担心的一种解释**是：这是持续排斥，并伴有公开羞辱或损害声誉的行为。支持这一解释的，是你报告的反复移群，以及尴尬视频和作弊说法都涉及公开场合。

**合理的替代解释**是：群聊可能因活动安排或成员管理而变动；视频的剪辑和传播可能被不同人以不同方式理解；作弊说法也可能源自误解、未经核实的传言，或某个具体争议。目前没有足够信息判断这些解释是否成立，也没有反证足以排除霸凌的可能。

最能帮助分辨情况的信息包括：每次移群的大致时间和前后发生的事、视频是否保留了改变含义的上下文、作弊说法由谁提出及是否有人说明依据，以及有人询问或要求停止后发生了什么。若你愿意，可以只分享去掉姓名等身份信息的简短摘要，不需要提供整份聊天记录。

## 可选的安全步骤

1. **做简短的私人记录**：记下大致日期、场景、你亲眼看到或亲自收到的内容，以及对你的影响；区分亲历和他人转述。只有在你觉得安全、有用时才做。
2. **找一位可信任的成年人或校内支持人员谈谈**：可以先询问学校有哪些支持或处理渠道，不必一开始就决定是否正式报告。说明组织者的影响力，以及你担心的事情可能怎样影响你。
3. **先处理最想解决的一件事**：例如确认是否有人散布作弊说法、减少尴尬视频继续传播，或获得参加活动所需的信息。可以请可信的人陪你沟通；不必独自对质或公开回应。

你可以按自己觉得安全的程度选择，也可以暂时不采取这些步骤。
````
