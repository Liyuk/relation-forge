# 02 兼职任务先返小钱、后要求垫资

> **演示类型：** 工作邀约、虚假余额与追加付款
> **材料性质：** 合成对话，不是真实受害者个案。情节只借鉴下方公开来源描述的风险线索；姓名、金额、时间线和措辞均为模拟。
> **本例想看：** 增益中等。两种输出的即时建议相近；Skill 把步骤和未知项列得更可复核，帮助使用者自己看出“之前提现过”为什么不是安全证据。

## 在线来源提供了什么

来源：[FTC：任务骗局制造赚钱假象](https://consumer.ftc.gov/consumer-alerts/2024/11/task-scams-create-illusion-making-money)（查阅日期：2026-09-25）

FTC 描述的任务骗局会先让人完成简单、重复的线上任务，再在应用中显示不断增加的虚假收入；随后要求先存入自己的钱，才能继续任务或取出显示的收益。

**局限：** 线上任务或计件工资本身不证明诈骗；示例的风险来自“先垫钱才能领取收入”与限时冻结威胁的组合。

## 合成用户输入

> 兼职群先返了我 50 元，现在客服说要垫 3000 元才能解锁大单佣金，半小时内不交就冻结余额。我已提现过一次。帮我拆一下这个流程。

## 这组材料说明什么

普通输出已经抓住“先返小额—再催大额垫款”的套路并给出止损步骤。Skill 输出逐项拆开小额返款、曾经提现、这次充值要求和冻结倒计时，说明前两件事不能验证后续收益，并标出客服身份、收款方和平台规则仍未知。

### 普通回答

````text
这很像“刷单返利／任务佣金”骗局：先返你 50 元建立信任，再要求垫 3000 元“解锁佣金”，还用“半小时内不交就冻结余额”制造紧迫感。你已经提现过一次，也不能证明后续安全；小额返款常被用来诱导继续投入。

**现在先这样处理：**

- **别再转 3000 元，也别交任何解冻费、保证金或税费。** 不要点客服发来的链接，也别提供验证码、银行卡密码或远程控制权限。
- 保存群聊、客服账号、转账记录、收款账户、平台网址和提现记录的截图；不要删聊天或卸载相关应用。
- 如果已经转过钱，马上联系付款银行或支付平台，说明疑似诈骗并申请拦截、止付或争议处理；同时联系当地警方／反诈渠道报案。越早越好，但不保证一定能追回。
- 如果给过银行卡、身份证、验证码或安装过不明软件，尽快联系银行冻结或更换相关凭证，并从可信设备卸载软件、检查账户登录与支付设置。
- 后续若有人声称能“追回本金”，但要先收费，也按高风险处理。

判断关键不在那 50 元是否到账，而在于**对方要求你先垫钱才能拿到佣金，并用限时冻结施压**。这已经足以停止付款并按疑似诈骗处理。
````

### 使用 Skill 的回答

````text
**先别交这 3000 元。**“先返 50 元”不能证明平台可靠；现在又要求垫资才能解锁佣金，并用半小时倒计时和冻结余额催付款，风险很高。你不需要先证明对方有诈骗意图，才可以暂停转账。

按你提供的信息，流程是：

1. 你加入兼职群。
2. 对方先返了你 50 元；你也曾成功提现一次。这说明你确实收到过钱，但不能证明后续任务和佣金真实。
3. 现在客服要求你垫 3000 元，声称这样才能解锁“大单佣金”。
4. 对方给出半小时期限，并威胁不付款就冻结余额。

**值得警惕的是这组行为连在一起：**先让你看到小额回款或提现，再要求先垫资才能取得更大的收益，同时用限时和冻结余额施压。这符合常见的刷单或任务垫资风险模式；但仅凭目前材料，不能确认对方身份、真实动机或法律责任。你提现过一次，并不等于平台之后会放款，也不等于继续充值安全。

现在可以先做这几件事：

- 暂停转账、充值和任何“解冻费”“税费”或补单要求，也不要给验证码、密码或安装远程控制软件。
- 不使用客服发来的链接或电话；若对方声称代表某个平台，自己从已知官方渠道查找联系方式核实。
- 如果已经转过其他钱，尽快通过你自己找到的银行或支付平台官方渠道询问处置方式；保留已有的交易信息即可，不必为了取证继续和对方周旋。

**现在最重要的是不再追加资金。**你可以只告诉我：除已提现的 50 元外，有没有另外转过钱，或交过验证码、密码？不要发账号、卡号或验证码。
````
