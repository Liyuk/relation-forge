# 07 单次记忆冲突与“煤气灯”误判

> **演示类型：** 关系冲突中的误报控制
> **材料性质：** 合成情境与模型回答，不是真实个案或专业裁定。

## 来源与边界

本例是边界测试：单次忘记约定不应直接升级为操控模式。研究来源清单的霸凌定义材料也强调不能把单次分歧简单归为霸凌；本例用于检查同一类误判边界。

## 合成用户输入

> 伴侣不记得上周约好周六见我，我很难过。这就是煤气灯吗？

## 验证记录

本例用两个独立的新会话做了定性对照；下面保留回答原文，方便读者检查差异。这不是盲评或准确率测试。

## 这组材料说明什么

两种回答都明确说单次忘记不够判断煤气灯，并建议核对约定、观察后续回应。Skill 没有造成可见的重大差异；普通回答已达到本例目标。

### 普通回答

````text
不一定。一次忘记约定，可能是粗心、记忆不一致或沟通出了岔子；“煤气灯”通常指反复否认或扭曲事实，让你逐渐怀疑自己的记忆、判断或现实感。

你可以先平静地说：“我记得我们约好周六见面，你忘了让我很难过。我们对这件事的记忆不一样，你愿意一起看看聊天记录吗？”重点观察对方接下来是否愿意倾听、核实并承担影响，还是经常嘲笑你、否认明明发生过的事，或把问题变成“你太敏感、你记错了”。

无论这是不是煤气灯，你的难过都是真的，也值得被认真对待。
````

### 使用 Skill 的回答

````text
光凭这一次，还不能判断是煤气灯。伴侣忘了约定，可能是普通的记忆疏漏；“煤气灯”更值得关注的是反复否认你记得的事、扭曲事实，或让你怀疑自己的记忆和判断。

你难过是可以理解的：你期待见面，而约定似乎没被记住。可以先看看原来的消息，或平静地说：“我记得我们约了周六见面。我很期待，所以你不记得时我挺难过的。我们要不要确认一下之后的安排？”留意对方是否愿意核对、理解影响并一起解决，还是经常否认约定、责怪你“记错了”或“太敏感”。

如果你愿意，可以说说他当时怎么回应的，以及这种情况是否反复发生。
````
