# RelationForge：看证据，保留选择

> 项目介绍素材，可用于博客或项目页面。以下例子均为合成文本。

遇到可疑转账、情绪勒索或职场霸凌时，人常常先问：“是不是我想多了？”“他到底是不是 NPD？”“我是不是太蠢才会被骗？”这类问题很容易把注意力带到给人定性，反而漏掉眼前可核对的行为：有没有被催着付款、能不能独立核实、拒绝之后发生了什么、类似事件是否反复出现。

RelationForge 提供两个可独立安装的 Agent Skill。它的核心原则是：**拆事实，看言行，辨风险，不替人定性。** **互动风险识别与解构**（`interaction-risk-analysis`）用于网恋及其他诈骗、情绪操控与虐待、胁迫，以及职场和人际霸凌；它帮助用户看见事件顺序、行为效果、可能解释、未知和可核实的下一步。**人际深度解析**（`person-deep-analysis`）用于自述、个人介绍、选取的聊天/互动材料或虚构角色；它帮助用户分清材料明确表达了什么，以及哪些只是有限的候选解释。

## 互动风险：从事件走向可核验的选择

模型本身能识别许多熟悉模式，但直接给出“这是操控/骗局”还不够。`interaction-risk-analysis` 要求先拆材料，再讨论解释。

假设有人说：“别问那么多，信我就把钱转过来。”你提出先核实公司，对方又说：“不转就是不爱我。”Skill 会先拆出催款、阻止独立核实、把付款与感情绑定这些行为；接着解释它们怎样压缩考虑和拒绝的空间，再提出“可能在回避核验”等有限目的假设，并列出“也可能把核验误解为不信任”等替代解释。效果值得重视，但效果本身不能证明对方的主观意图。

用户可以暂停转账、通过自己找到的官方渠道核验，也可以先不作最终判断。如果风险正在发生，Skill 应先给出简洁的安全选择，不拿追问拖延止损。

这不是“用问题诱导人相信 AI”。问题允许回答“我不确定”“那条线索可能有别的解释”，也允许用户不回答。**不确定对方动机，不妨碍一个人先保护自己的钱、边界和安全。**

## 人际材料：解释有限，尊重主体性

`person-deep-analysis` 可用于理解一段自述写出的需求与选择、几段聊天中的可见互动，或作品如何呈现虚构角色。它先引用具体材料，再提出有依据的候选解释、合理替代解释和未知；不会由一段文案推断稳定人格或编造成长经历。只有用户明确要求时，才展开多个心理学视角。不同视角是思考工具，不会因为数量多就变成更强的证据。

## 两者共同的边界

只有一次记忆分歧，不自动等于煤气灯；一次具体、私下且有改进支持的工作反馈，不自动等于霸凌；一张收款账号变更的发票值得核实，但材料不足时不应直接判成诈骗。相反，反复催款、隔离朋友、威胁隐私、公开羞辱或提出异议后遭报复，也不该因为“也许只是玩笑”就被轻轻带过。

两个 Skill 都把原话、行为、来源、重复性、影响和反面信息分开处理，不诊断 NPD 或“黑暗人格”，不按文本预测犯罪，也不要求受影响者先证明恶意才能暂停付款、拒绝要求或求助。人物解读不能代替对催款、威胁或控制行为的现实应对。

## 为什么做成 Skill

安装后，用户可以把所需 Skill 带到自己的 AI 助手里，用自然语言描述问题或提供去标识后的少量摘录。互动风险分析按时间拆解说法、行为、回应和后果；人际深度解析按问题选择相关的人物、关系或叙事材料。两者都检查依据、替代解释与未知，并只展开当前问题需要的内容。

两个 Skill 的共同纪律是：**具体证据先于标签，行为效果与主观目的分开，解释可以检验和修正，决定权仍属于当事人。**
