# RelationForge：下一阶段可扩充的分析面

## 研究目的

现有 Skill 已覆盖事实/推断区分、立场与利益、信息缺口、诱导动作、群体压力、拒绝反应、可逆性和独立核验。本笔记研究下一阶段最值得补充的机制：哪些因素会让错误叙事变得“像真的”、为什么纠错后影响仍会留下、信息界面如何参与诱导，以及如何把识别转成更稳妥的防御动作。

这不是把更多心理学标签加入输出，而是寻找能改变分析和行动的机制。

## 主要发现

### 1. 重复不是独立证据，但会制造熟悉感

实验研究持续观察到，重复接触一个陈述会提高其主观真实感；近期研究还提示，重复产生的效果与陈述内部的语义连贯性有关。[Udry & Barber, 2023](https://pubmed.ncbi.nlm.nih.gov/37742428/)；关于重复频率的实验研究见 [Cognitive Research, 2021](https://link.springer.com/article/10.1186/s41235-021-00301-5)。

对 Skill 的意义：增加“来源独立性”检查。分析“大家都这么说”“不同账号都发了”“我已经听过很多次”时，不要只统计次数，还要追问：是否同源、是否互相引用、是否由同一利益网络推动。输出可以明确区分：

- **熟悉度增加**：这条说法更容易被想起。
- **证据增加**：出现了新的、独立且可核验的支持。

二者不能混为一谈。

### 2. 纠错不一定移除原来的叙事

“继续影响效应”指错误信息即使被纠正，仍可能继续影响判断；相关研究还发现，信息与既有态度一致时，纠错后的影响可能更难消退。[Susmann & Wegener, 2023](https://pubmed.ncbi.nlm.nih.gov/35227114/)；一篇近期综述将其机制区分为认知、动机和理性层面。[Laurent et al., 2026](https://pubmed.ncbi.nlm.nih.gov/42374655/)

对 Skill 的意义：不要只写“这句话是假的”，还要补一个能解释事件的替代叙事：

1. 原来让人相信的故事是什么？
2. 哪个事实削弱了它？
3. 如果不采用原故事，当前事件更合理的解释是什么？
4. 后续哪些行为能区分这两个解释？

这尤其适合处理“已经被骗过、已经转过钱、已经公开指责某人”之后的复盘。目标不是要求用户立刻相信新结论，而是帮助其摆脱旧叙事对下一步行动的继续影响。

### 3. 注意力本身是被争夺的资源

一项 Nature 研究发现，人们分享错误信息时，注意力常常集中在新奇、情绪或社交反应等因素，而不是准确性；将注意力短暂拉回“这是否准确”可以减少错误信息分享。[Pennycook et al., 2021](https://doi.org/10.1038/s41586-021-03344-2)；后续研究报告了准确性提示在不同材料和样本中的可重复性，但也指出它需要使用者至少有能力初步判断内容可靠性。[Pennycook & Rand, 2022](https://www.nature.com/articles/s41467-022-30073-5)

对 Skill 的意义：增加“注意力检查”：

- 对方是否把你从事实问题引向愤怒、恐惧、羞耻、身份认同或群体对立？
- 当前最醒目的部分，是证据，还是情绪和倒计时？
- 如果去掉头像、称号、音乐、评论数和情绪化措辞，剩下什么可验证事实？

反诱导动作不一定先反驳内容，也可以先恢复准确性注意：暂停转发、付款或回复，单独写出主张和证据。

### 4. 纠偏需要“替代机制”，不能只有否定

认知免疫/预防性识别研究把防御分为两部分：提前提醒人们可能遇到操控，再用较弱的示例展示操控手法和反制方式。[Nature Medicine, 2022](https://www.nature.com/articles/s41591-022-01713-6)；针对论证手法的实验也研究了预先暴露与反驳如何降低误导影响。[Roozenbeek et al., 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5419564/)

但不能把“预防性识别”写成万能护盾。近期跨国实验发现，部分预防性干预的保护效果有限；显著的纠偏干预还可能提高一般性怀疑，而不只是降低特定误解。[Nature Human Behaviour, 2024](https://www.nature.com/articles/s41562-024-01884-x)

对 Skill 的意义：反诱导回答要给“识别机制 + 替代行动”，例如：

- 不只说“这是制造紧迫感”，还说“把决定延迟到明天，并从独立渠道核实”。
- 不只说“这些见证可能同源”，还说“追溯最初来源，并找一个圈外、利益不同的来源”。
- 不只说“截图不能证明”，还说“核对资金主体、合同、退出条件和官方联系方式”。

### 5. 界面和流程本身也可能在诱导

FTC 对数字暗黑模式的报告归纳了伪装广告、隐藏关键条款、虚假社会证明、稀缺性提示、让取消变得困难以及诱导分享数据等做法。[FTC, 2022](https://www.ftc.gov/reports/bringing-dark-patterns-light)

对 Skill 的意义：遇到平台、投资页面、课程销售或订阅流程时，不只分析文字和人物，也分析界面动作：

- 默认选项是否偏向付款、续费、授权或公开？
- 取消、退出和退款是否比进入更困难？
- 重要费用、限制和责任是否被折叠、延后或藏在次级页面？
- “已有很多人购买/成功”是否可独立核验？
- 页面是否把拒绝写成损失、羞耻或错过机会？

这把“对方在骗我吗”扩展成“整个选择环境是否在系统性地减少我的知情和退出空间”。

### 6. 控制模式要看权利和选择空间，而非单一事件

关于胁迫控制的综述强调，关键不是某一次威胁是否单独构成结论，而是持续的监控、孤立、限制资源和削弱权利是否形成了让人难以退出的模式。[Hamberger et al., 2017](https://pubmed.ncbi.nlm.nih.gov/30803427/)；相关系统综述也将隔离、监控和限制财务/社会资源作为需要结合模式分析的行为。[Systematic review, 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10666508/)

对 Skill 的意义：将“控制”操作化为选择空间变化：

- 用户还能否延迟、拒绝、核验、求助和离开？
- 每次拒绝是否带来更高的情绪、财务、社交或人身代价？
- 对方是否控制信息、联系人、设备、资金或解释权？

不要从单次强硬表达推断完整控制关系；也不要因为动机未知而忽略持续的选择空间收缩。

## 建议进入 Skill 的新增模块

### 高优先级

1. **来源独立性与重复曝光**：重复次数不等于证据数量。
2. **叙事替换与纠错后残留**：纠错时提供更好的因果解释，而非只否定。
3. **注意力检查**：识别情绪、身份、倒计时和社交反馈如何抢走准确性判断。
4. **界面/流程检查**：把暗黑模式、默认选项、隐藏费用和退出阻力纳入互动风险。

### 中优先级

5. **预防性识别**：用短小案例教用户识别机制，但明确效果有限，不能替代具体核验。
6. **控制模式与选择空间**：将监控、孤立、资源限制和拒绝成本放进同一条时间线。

### 暂不建议直接加入

- 更多人格类型或“骗子画像”。
- 一个覆盖所有情境的风险分数。
- 把每种认知偏差都单独命名。
- 把研究中的实验效应直接写成对某个具体人的动机结论。

## 推荐的下一版总流程

> **来源与独立性 → 对方叙事 → 信息缺口 → 注意力/情绪压力 → 诱导动作 → 利益流向 → 阶段与升级 → 拒绝/纠错反应 → 选择空间与可逆性 → 独立验证 → 替代叙事 → 行动阈值**

对外仍压缩成少量有用内容；完整流程作为复杂材料的后台检查。
