# 模块4：优势与情境成本

## 核心问题
材料中可见的优势，在什么具体情境下可能产生成本？

## 主要运用启发式
优势在压力或过度使用时可能带来成本；展示某项特质不代表其反面就是隐藏恐惧。

## 分析步骤

### 步骤1：识别当前材料中突出的表现

从对方信息中提取可见的自我呈现：
- 最先出现、反复出现的描述是什么？
- 本人使用了哪些自我标签？
- 哪些部分在此材料中被突出，哪些未被提及？

### 步骤2：提出待核实的成本假设

不要将特质机械翻转为隐藏恐惧。只在有具体行为或本人陈述时，讨论该优势在特定压力下可能产生的成本。

**判断原则**：反复展示只说明该特质在材料中突出；不能据此推断恐惧、压抑或“面具”。

### 步骤3：优势极端化风险

在有材料依据时，讨论优势过度使用可能产生的条件性成本：

| 分析角度 | 问题 |
|---------|------|
| 自我关系 | 这个优势过度发展会如何伤害他自己？ |
| 亲密关系 | 这个优势在伴侣视角会变成什么问题？ |
| 社交/工作 | 这个优势在其他场景的负面表现？ |
| 压力情境 | 高压下这个优势会扭曲成什么行为？ |

### 步骤4：标明尚未验证的情境成本

综合步骤2-3，提出待核实的条件性假设。描述可能发生摩擦的条件，不预测关系结局、风险概率或伴侣类型。

## 输出格式

```
### 优势与情境成本

**材料中突出的特质**：[只描述可观察呈现]
**可能成本**：[仅在有具体依据时填写；否则标为未知]
**极端化风险**：[该优势推到极端在关系中的问题表现]
**待核实的情境成本**：[有具体材料时描述成立条件；否则标为未知]
```
