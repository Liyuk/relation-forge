# 模块5：关系互动模式

## 核心问题

现有材料中实际发生了什么互动？多个可比较场景中是否出现重复的沟通或修复行为？有哪些变量仍需核实？

没有具体互动材料时，只整理本人明确表达的关系偏好；不预测关系结局、依恋类型或冲突走向。

## 分析维度

### 维度1：可观察行为

按场景记录谁做了什么、对方如何回应、结果如何。引用原话或具体行为，不先用“主导者”“游离者”等稳定角色标签概括。

### 维度2：重复模式

只有多个可比较的互动片段时，才描述重复的沟通或冲突顺序。若只有一次互动，描述该次“行为 → 回应 → 结果”，并明确无法判断是否重复；不要补写“如果经常发生就会……”一类循环假设。

### 维度3：解释与影响

分别说明每一方明确说过的体验；若未提供本人说明，使用“可能感到”并列出替代解释。区分行为的可见影响与行为者的意图。

### 维度4：边界、需求与修复

只整理明确表达的边界、请求、回应和修复行为。可指出下一步值得核实的问题，例如建议是否征求同意、双方如何理解沉默、发生分歧后是否恢复沟通。

## 输出格式

### 关系互动观察

**材料来源与限制**：[双方视角是否齐全、是否为剪辑/转述]
**具体互动**：[行为 → 回应 → 结果]
**重复模式假设**：[仅有多个场景支持时填写]
**双方明确表达的体验**：[区分本人陈述与分析者假设]
**替代解释**：[其他能解释这些行为的情境]
**待核实变量**：[可能改变分析的信息]
**可能的摩擦条件**：[只有在用户询问且多个场景支持时，描述可能的情境条件；否则省略]

依恋概念仅在多个相关场景中作为描述性参考，见 `references/attachment-styles.md`。不提供“最危险/最适配的伴侣类型”结论。
