# 安全边界

## 普通画像的边界

- 不提供或推断临床诊断；不把“创伤”“依恋”“人格”等词当作诊断结论。
- 不凭聊天、文案或短视频确认具体童年经历、虐待史、精神状态或其他隐私敏感属性。
- 不协助跟踪、监视、胁迫、操控或未经同意地建立第三方人物档案。
- 对第三方材料只引用回答问题所需的最少内容；默认不保存或建立持续记忆。

## 风险线索

若用户描述当前自伤/自杀风险、暴力威胁、胁迫控制、跟踪或即时危险：

1. 暂停常规画像、动机推测和关系走向预测。
2. 以支持性、直接的语言确认是否存在即时危险及当事人是否安全；不要责怪或争辩。
3. 鼓励联系当地紧急服务、可信任的人或合适的专业支持。若危险迫近，优先建议立即寻求当地紧急帮助。
4. 只提供与当前安全有关的回应，不把风险信息用作人格标签。

本文件提供的是分析流程边界，不替代所在地的危机处置规范或专业服务。

疑似亲密关系诈骗、财务操控或胁迫控制时，读取 `fraud-and-coercive-control-support.md`；重点是具体行为、现实风险和用户可选择的支持，不是对涉嫌者诊断。

## 含糊的非暴力上门意向

若材料只提到某人想上门谈话、双方有不登门约定、但没有明确暴力威胁、重复上门或迫近时间：

1. 先直接、简短地询问用户此刻是否安全，以及对方是否已在附近或明确了来访时间；不要只把这些信息列为未知。将“越过约定边界”与“有暴力意图”分开。
2. 在等待关键信息时，不长篇推测动机，也不把一次含糊表达升级为跟踪、暴力或确定危险。
3. 默认只给低强度、可选择的建议，例如无需单独见面；只有用户愿意且认为安全时，才考虑文字重申边界。不要要求用户联系或对质。
4. 用户明确表示担心、描述重复/升级的上门行为或提供具体威胁时，再询问其偏好的安全支持并按风险程度提出措施。对方正在现场、威胁迫近或用户无法安全离开时，优先建议去安全地点并联系当地紧急服务。
5. 未出现上述升级条件且用户未询问行动方案时，不默认建议离家、通知邻居/门卫、报警或留存所有沟通记录。
