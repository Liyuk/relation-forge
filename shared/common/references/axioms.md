# 八条分析启发式

> “公理”是项目沿用的名称。以下内容用于生成候选问题，不是已验证的心理学定律。任何单一信号都不能证明需求、动机、创伤、人格或依恋类型；应考虑上下文、文化、文体、现实条件和反例。

## 1. 外显表达可能提示需求

反复强调、展示、要求或排斥某项内容时，可以询问它是否对当事人重要。它也可能只是偏好、现实安排、平台文体或文化规范。

**可观察线索**：重复出现的要求、边界、期待或拒绝。
**核实方向**：本人如何解释这项偏好？它是硬性条件还是倾向？

## 2. 对外要求可能提示价值

理想对象或相处条件可能反映本人重视的价值，也可能来自生活目标、外部规范或筛选需要。

**可观察线索**：择偶/交友标准、相处方式期待、明确的排斥项。
**核实方向**：这项条件服务于什么具体生活安排？有哪些弹性？

## 3. 当前行为可能受经验影响

既往经验可能影响当前行为，但不能由当前行为反推发生过某件事，更不能猜测具体童年或关系经历。只有本人明确提供相关经验时，才用 M3 整理。

**可观察线索**：本人直接讲述的经历，以及本人如何描述其与当前行为的联系。
**核实方向**：这是本人明确建立的联系，还是分析者提出的有限假设？有哪些当前情境解释？

## 4. 优势可能伴随情境成本

某项优势在特定压力下可能有成本；展示一个特质不表示其反面就是隐藏恐惧。

| 可见特质 | 可核实的问题 |
|---|---|
| 独立、自主 | 本人如何看待协作和求助？ |
| 理性、冷静 | 在其他场景中如何表达感受？ |
| 有主见、果断 | 协商时如何处理不同意见？ |
| 温和、体贴 | 本人如何表达不同意和边界？ |
| 高标准、重视品质 | 标准如何应用，是否影响合作？ |
| 幽默、轻松 | 严肃话题出现时能否切换沟通方式？ |

## 5. 语言结构可能提示互动位置

句式和语气可以帮助描述一段对话中的互动方式，但不能脱离内容确定权力诉求或心理需求。

| 表达方式 | 可描述的互动线索 | 核实方向 |
|---|---|---|
| “我要求…”“底线是…” | 明确提出规则或条件 | 规则如何协商？适用于什么情境？ |
| “别误解我…” | 补充说明或澄清 | 前文发生了什么？ |
| “如果你不能…” | 设置条件或结束选项 | 这是偏好、边界还是现实要求？ |
| “希望一起…” | 提出共同活动期待 | 双方是否都同意？ |
| 自嘲或降低期待 | 使用自我调侃表达 | 语气和前后文如何？不推断防御动机。 |

## 6. 描述重复的亲密互动

只在多个具体关系场景中描述重复的亲密、距离、冲突和修复行为。不从单次反应或文案给人归类；依恋概念参考 `attachment-styles.md`。

| 多个场景中的观察 | 中性描述 |
|---|---|
| 能提出请求并参与协商 | 在这些场景中表现出直接沟通 |
| 多次确认联系或关系安排 | 在这些场景中频繁确认安排 |
| 多次暂停或减少冲突沟通 | 在这些场景中倾向拉开距离 |
| 接近与退开交替出现 | 在这些场景中出现不一致的互动节奏 |

## 7. 选择可能提示当时的优先级

具体选择可能反映当时的权衡，但会受资源、机会、义务和信息影响，不能据此推断固定的“真实排序”。

**观察方法**：对比明确表达与实际选择；先核实可选项、时间、资源和情境。

## 8. 社会比较可能构成参照背景

仅当材料明确出现比较对象或相对位置时，才讨论社会比较；焦虑、优越感、孤独或自我评价变化也可能有其他原因。

| 可观察表述 | 核实方向 |
|---|---|
| 提及更高成就的比较对象 | 这种比较是否影响其选择或感受？ |
| 强调圈层匹配或门当户对 | 现实兼容性、社交规范或自我评价，哪种更相关？ |
| 强调与众不同 | 是具体差异描述，还是对标签的回应？ |
| 描述与他人的差异 | 这在当前材料中起什么作用？还有哪些上下文？ |
