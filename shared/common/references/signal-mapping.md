# 信号与核实问题

本文件用来从可观察材料生成下一步问题，不把某个表达映射成心理事实。单一信号不能确认内在缺失、投射、创伤、权力动机或依恋类型。先记录原话和上下文，再提出可被新信息修正的假设。

| 可观察材料 | 可探索的方向 | 应核实的问题/替代解释 |
|---|---|---|
| 反复强调关系确定性、承诺或边界 | 可能重视清晰安排与可预期性 | 这是现实规划、当前关系状态、个人偏好还是过往经验？“确定”具体指什么？ |
| 列出学历、收入、居住地等筛选条件 | 可能重视现实兼容性或共同目标 | 这些是硬性条件、偏好还是平台文案惯例？背后的生活安排是什么？ |
| 描述独自旅行，同时希望未来共享活动 | 可能同时重视自主空间与共同体验 | 是否感到孤独需要本人说明；独行本身不能证明缺少陪伴。 |
| 对未征求意见的建议表达抵触 | 可能重视自主权或希望先被倾听 | 是否曾请求建议？争执是否重复？建议内容、时机和语气分别如何？ |
| 对某件事反复解释或补充 | 可能希望避免误解或补足上下文 | 话题本身是否复杂？对方是否追问？不能据此确认羞耻、弱势或创伤。 |
| 同一人出现言行差异 | 可能存在目标冲突或情境变化 | 时间、受众、资源和义务是否改变？是否有具体行为可供比较？ |
| 多个关系场景中反复出现相近的靠近/退开反应 | 可描述为重复互动模式 | 是否存在跨场景材料？不同伴侣和现实压力是否导致不同反应？不因此推断早期经历。 |
| 讲述冲突时突出某类事件、略过另一些内容 | 可描述叙述选择与信息缺口 | 讲述目的、记忆、受众和材料剪辑如何影响呈现？不据此定性讲述者动机。 |

## 使用规则

- “可能方向”用于组织澄清问题，不直接写进结论。
- 如果本人已经说明原因，准确转述为本人报告，并与分析者推断分开。
- 若没有进一步材料，明确写“无法判断”，不从本表补造故事。
- 有多种同样合理的解释时并列保留，指出什么信息能区分它们。
