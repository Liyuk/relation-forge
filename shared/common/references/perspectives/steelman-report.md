# 多视角 Steelman 报告

## 何时使用

仅在用户明确请求多流派、多视角或 Steelman 深入报告时使用。普通请求保持简洁。先查看各镜头的适用边界；用户要求列出全部学派时，逐项标为“可有限应用”或“材料不足/不适用”，不可强行填满。

## 工作步骤

1. **固定事实底座**：引用最少的原话/行为，标明来源、情境和上下文缺口。
2. **检查视角适用性**：只让材料适合的视角提出解释。对不适用视角简短说明原因。
3. **构造 Steelman**：将每个有材料支持的解释写成该视角下最强、最合理的候选版本，并列出具体依据和它额外依赖的假设。
4. **检验竞争解释**：给出能够解释同一材料的最强合理替代项，以及会削弱当前解释的反例或待核实信息。没有合理替代项时明说，不虚构反方。
5. **并列而不投票**：指出不同镜头共享哪些观察、回答的是哪些不同问题、解释在哪些地方仍冲突。重复出现的理论术语不算独立证据。
6. **收束范围**：总结当前可说与不可说的内容。不给诊断、人格分数、因果确定性、关系结局或犯罪风险预测。

Steelman 要公平对待材料确实支持的竞争解释，不意味着解释等概率、观点都一样有证据，或需要同时提供“好人/坏人”版本。结论强度依赖材料质量与独立证据，不依赖用了几个流派。

## 建议输出

```text
问题与材料边界：来源、时序、视角和上下文
共同观察：少量可核对的原话/行为
视角 A：适用性；最强候选解释；依据；额外假设；反例/未知
视角 B：适用性；最强候选解释；依据；额外假设；反例/未知
不适用视角：为什么当前材料无法支持有用分析
交叉比较：共同事实、解释分歧、可区分假设的新增信息
结论边界：材料支持到哪一步，不能据此确认什么
```

报告长度服从用户需要和材料量。少量材料下可以只有一个有效视角，其余明确省略。

用户要求简短时，压缩每项说明，不删除 Steelman 的关键检查：候选解释及材料依据、额外假设、最强合理替代解释、可能削弱解释的信息。材料无法支持其中一项时，直接标注“材料不足”或“不适用”；不要为填齐格式而编造内容。
