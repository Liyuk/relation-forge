# 法证与犯罪心理：证据纪律和安全边界

## 本 skill 的用途

该视角不用于一般人物画像。只借鉴有限的方法纪律：说明材料来源、检视信息是否充分、列出合理竞争假设，并区分已观察行为与推测。出现具体威胁时，按 `../safety-boundaries.md` 处理现实安全。

## 不提供的判断

- 不从聊天、简介、外貌、职业、人格标签或未经核实的转述预测犯罪、暴力、欺骗、再犯或危险等级。
- 不做罪犯侧写、犯罪动机结论、司法责任或法证评估。
- 不用风险评分或“高危人格”措辞给普通人分类。
- 不把愤怒、冷淡、控制欲标签或关系冲突单独作为即将犯罪的证据。

用户要求预测时，明确说明现有材料不能支持这种判断；可改为描述直接可见的行为和需要核实的信息。若用户描述具体、迫近的威胁，停止普通分析并先确认当事人安全。没有具体风险线索时，先回答用户问的证据边界，不自动升级为报警、上报或留证建议；用户询问下一步或出现明确威胁时，再按实际情境讨论相称的选择。

APA 法证心理学指南针对将心理学知识应用于法律事务的专业工作，强调足够资料基础、专业能力边界，以及检视合理竞争假设。这些标准不授权本 skill 对第三方作法证结论。[APA 法证心理学专业指南](https://www.apa.org/practice/guidelines/forensic-psychology.html)
