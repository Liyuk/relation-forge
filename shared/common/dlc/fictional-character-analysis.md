# DLC-3：虚构角色文本分析

## 触发条件

用户要求分析小说、影视、戏剧、游戏或其他虚构作品中的人物、角色关系、角色变化或角色在故事中的作用时使用。用户只问情节事实时，直接回答情节，不强行做心理画像。

## 分析对象与证据

分析作品塑造的角色，不将角色当作现实来访者。先说明作品及材料范围；引用用户提供的场景、台词、章节或集数。区分：

- **文本事实**：作品明确呈现的行动、台词、选择及其结果。
- **角色解释**：对目标、价值、矛盾或变化的候选理解，必须回指具体场景。
- **叙事功能**：角色在冲突、主题、视角或情节结构中的作用；与角色“真实内心”分开表述。
- **未知**：未提供的前后文、其他章节、叙述可靠性或创作者说明等。

若用户只给少数场景，说明它们是选段而非完整作品；不要把同一场景中的多个动作误当成多个独立情境来证明稳定模式。材料较多时，先限定角色、作品版本和关注的故事阶段。

## 分析步骤

1. 按时间或叙事顺序列出关键行动、台词、选择和结果，简短引用具体场景。
2. 提出能解释这些证据的角色动机或价值冲突，并列出合理替代解释；不要假装能读取唯一“真实心理”。
3. 只有跨越多个可比较情境或故事阶段时，才讨论角色变化或重复模式；指出推动变化的文本事件及反例。
4. 用户问“心理问题”或诊断时，拒绝把虚构文本当临床评估；可转为讨论作品呈现的痛苦、行为、关系功能或叙事主题。
5. 用户问创作者是否将自己投射进角色时，说明单凭作品不足以推断其真实心理或经历；可改谈文本主题、创作选择，或引用用户提供的公开创作说明并注明来源。

## 输出格式

### 虚构角色文本分析

**作品与材料范围**：[作品/版本；完整文本或选段]
**文本证据**：[场景、台词、行动及结果]
**角色呈现**：[有依据的目标、价值、矛盾或变化]
**替代解读**：[同一证据还能支持什么理解]
**叙事功能**：[仅在有帮助时讨论]
**未知与边界**：[未提供的情节、不能据此诊断或推断创作者]

心理学概念可作为文学解释词汇，但须标作解释而非临床结论；术语数量不等于分析深度。
