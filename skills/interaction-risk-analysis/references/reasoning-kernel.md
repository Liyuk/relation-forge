# 复杂判断的推理内核

这份参考用于复杂判断、争议、因果、风险和方案选择。它是后台检查清单，不是固定输出模板。

## 一条主线

> **事实 → 关键假设 → 证据质量 → 因果与替代解释 → 立场与利益 → 关键新信息**

涉及现实决定或迫近风险时，再追加风险不对称、可逆性和行动阈值。

### 1. 事实与假设

- 把直接看到/听到的内容、转述、推断和猜测分开。
- 找出当前结论最依赖的一个或两个假设。
- 问：这个假设一旦不成立，结论会不会明显改变？

### 2. 证据与因果

- 来源是原始记录、官方资料、独立观察、专业意见、群体重复还是个人说法？
- 来源是否独立，是否存在利益冲突或选择性呈现？
- 不把“先发生”直接写成“导致”。检查机制、混杂变量、反向因果和替代解释。
- 优先寻找能区分解释、成本低且不增加风险的信息。

### 3. 立场与利益

- 谁想得到什么，承担什么成本，受到什么约束？
- 谁掌握更多信息，谁能决定规则、时间和退出条件？
- 谁从当前叙事或方案中获益，谁承担风险？
- 利益冲突提高核验要求，但不自动证明对方在说谎。

### 4. 反方与校准

- 构造最强的合理反方，而不是找一个容易击败的版本。
- 如果反方确实削弱结论，就降低结论强度。
- 明确置信度：高、中、低或无法判断；说明最脆弱的环节。
- 必须能回答：“什么证据会让我改变判断？”
- 分别校准具体命题：可见的筛选、行为造成的效果、故意设计的主观目的，证据门槛依次提高。缺少基准率或可校准数据时，不给主观动机编造数字概率；可以比较解释的相对依据和不确定性。

### 5. 风险与行动

- 判断错误的损失是否不对称，是否存在小概率大损失？
- 决定是否可逆，撤回成本多高，能否先小范围验证？
- 问：当前信息是否已经足够支持行动？不必等待绝对确定。
- 高风险、不可逆动作提高证据门槛；低风险、可逆动作可以先做小试验。
- 方案要检查最可能的失败方式、单点故障和二阶后果。

## 遇到诱导时的优先顺序

对方试图让用户立即付款、保密、转移平台、交出凭证、切断支持或承担不可逆风险时，优先执行：

1. 暂停不可逆动作。
2. 分开事实、对方解释和对方要求。
3. 找出信息缺口、利益流向和关键假设。
4. 从独立渠道寻找一条高信息价值、低风险的核验。
5. 再决定是否继续、缩小范围、拒绝或退出。

动机未知不等于行动无门槛；无法证明恶意，也不等于必须承担高损失风险。

## 输出压缩

用户只问分析时，默认只展示：

> **当前判断 → 关键事实和利益结构 → 真正影响判断的未知或替代解释**

用户问怎么办、正在作重要决定时，再补风险、可逆性和少量可选做法；迫近危险先简短止损。只有用户要求完整推理，或问题确实复杂时，才展开假设、证据、因果、反方和失败模式。不要为了显示完整而输出所有检查项。
