# 群体压力、从众与焦虑放大

“很多人都这么说”不是独立证据。分析群聊、评论区、直播间或社群时，检查：信息是否同源；参与者是否有共同利益；是否用统一口径、起哄、倒计时、稀缺名额或共同敌人制造行动压力；提出异议的人是否被嘲笑、踢出或指责为不合群。

常见焦虑链条是：

> 模糊威胁 → 解释最坏结果 → 缩短决定时间 → 声称只有一个解决方案 → 要求不可逆行动

把威胁是否真实、对方是否有权解决、所要求的行动是否真的能解决分开。焦虑是真实感受，但不等于对方的解释真实。

对抗时追溯原始来源、记录时间线、寻求圈外意见、争取延迟，并把多数换成可复核事实。描述群体造成的实际压力和权力结构，不凭一次起哄给所有参与者定性。
