# 复杂判断的推理内核

这份参考用于复杂判断、争议、因果、风险和方案选择。它是后台检查清单，不是固定输出模板。

## 一条主线

> **事实 → 关键假设 → 证据质量 → 因果与替代解释 → 立场与利益 → 关键新信息**

只有涉及现实决定或迫近风险时，才追加风险不对称、可逆性和行动阈值。

分析自述、征友贴或对话时，特别检查表达是否在引导读者形成某种判断，以及说法、行动和利益流向是否一致。

## 检查重点

- 把直接材料、转述、推断和猜测分开。
- 找出当前结论最依赖的假设；问它一旦不成立，结论是否会改变。
- 检查来源是否独立、是否存在利益冲突、选择性呈现或群体同源重复。
- 不把时间顺序直接写成因果；比较机制、混杂变量、反向因果和替代解释。
- 分别整理用户想保护什么、对方想得到什么、谁掌握信息和退出权、谁承担成本。
- 构造最强合理反方；如果反方削弱判断，就降低结论强度。
- 校准置信度，并明确什么证据会改变判断。
- 涉及决策时，判断损失是否不对称、决定是否可逆、能否先小范围验证，以及方案如何失败。

置信度要落在具体命题上：“文案在筛选读者”和“作者故意隐瞒”不是同一个判断。没有可用的基准率、独立样本或可校准模型时，不给主观动机编造数字概率；可以说哪种解释目前更有依据、依据强弱如何、什么证据会改变排序。

## 诱导情境

对方要求付款、保密、转平台、提供凭证、切断支持或立即作出不可逆决定时：先暂停，分开事实/解释/要求，找利益流向和关键缺口，再寻找独立且低风险的核验。动机未知不等于行动无门槛。

## 输出压缩

用户只问分析时，默认只展示：

> **当前判断 → 关键事实和利益结构 → 真正影响判断的未知或替代解释**

用户问怎么办或现实决定需要时，再补风险、可逆性与少量选择；迫近危险先简短止损。完整的假设、证据、因果、反方和失败模式只在用户要求或确实影响结论时展开。
