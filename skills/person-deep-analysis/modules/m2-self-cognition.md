# 模块2：自我认知（Self-Cognition Analysis）

## 核心问题
这个人如何定义“我是谁”，又希望读者因此如何看待自己、选择自己或回应自己？

自我介绍、征友贴、简历和对话都不是透明的内心报告，而是面向某个对象的表达行动。先看它在争取什么反应，再讨论它可能说明什么。

## 主要运用启发式
- 对外要求可能透露重要价值，也可能反映现实条件或筛选偏好。
- 实际选择可能提示当下优先级，但会受资源与义务影响。
- 仅在材料明确出现比较参照时分析社会比较。

这些维度用于描述材料呈现，不据此推断固定自我价值或内在动机。使用“呈现出”“可能重视”等措辞。

## 分析维度

### 维度0：表达面向谁、想换来什么

先问四个实际问题：

- 这段表达是对谁说的，预期对方相信什么？
- 说话者希望对方做什么：联系、选择、让步、付款、提供照顾，还是接受某种关系安排？
- 说话者突出什么、哪些相关信息没有出现？这些取舍可能如何影响读者的判断？不能仅凭未提及就断定有意降低戒心。
- 对方的需要和选择有没有被纳入，还是主要在描述“我是什么样、你要符合什么条件”？

这不等于把所有自我呈现都判定为欺骗。征友贴本来就会筛选和展示；关键是区分正常的自我呈现、单方面的利益筛选，以及说法与行动之间的落差。

推断分层：文本没有写某项条件，是可观察事实；它可能让特定读者更愿意回应，是需结合受众、文体和具体措辞的解释；说话者故意隐瞒、欺骗，则需要追问后的回避、前后矛盾、反复误导等额外证据。可以比较哪种解释更有材料支持，但不要凭单篇文案报出“70% 故意隐瞒”之类没有基准数据的数字概率。

### 维度1：文案中的自我呈现

记录文案突出了哪些方面，不据此判断自我价值来源：

| 呈现方向 | 可能突出的内容 | 常见材料 |
|---------|------|------|
| 条件信息 | 学历、工作、收入或外形 | 详细列出生活条件 |
| 特质描述 | 性格、才华或审美 | 强调个人品质与特点 |
| 体验描述 | 经历、兴趣或技能 | 展示旅行或长期爱好 |
| 关系角色 | 在关系中的具体行为 | 描述付出、照料或合作经历 |
| 成就信息 | 完成的项目或目标 | 罗列成果或里程碑 |

描述文案时，同时记录它对读者提出了什么隐含或明确的期待。比如“我很照顾人”只是自我描述；是否真的在关系中照顾对方，要看具体行动、是否尊重拒绝，以及照顾是否被用来换取服从或回报。

### 维度2：特质认同（我接纳自己什么）

- 对自身性格优缺点的接纳程度
- 是否坦然展示不完美
- 将哪些个人特质视为核心魅力
- 是否存在自我矛盾（想展示A面但又怕暴露B面）

### 维度3：对外要求可能反映的价值

| 可观察表达 | 可探索的解释 |
|---------|------|
| 要求对方有的特质 | 可能是本人重视、需要或认为与生活目标相符的条件 |
| 排斥对方有的特质 | 可能是边界、兼容性判断或过往经验影响 |
| 对相处模式的要求 | 可能描述其偏好的生活方式 |
| 对关系功能的定义 | 可能提示当前阶段重视的支持方式 |

### 维度4：材料中可见的排序与取舍

若本人在具体场景中比较过不同目标，可描述其当下如何排序或权衡，并引用相应表达。不要把一次权衡转换成“理性型”“感性型”“完美主义”等固定人格类型；没有具体取舍材料时省略此项。

## 输出格式

```
### 自我认知

**文案中的自我描述**：[概括其明确自述，不代替本人定义身份]

**表达的对象与诉求**：[希望读者如何理解/回应；哪些内容在吸引或筛选；若涉及降低警惕，说明额外证据]

**呈现重点**：[材料突出哪些方面] —— 论据
**特质认同**：[接纳什么/回避什么] —— 论据
**对外要求**：[可能体现哪些明确偏好] —— 论据与替代解释
**决策/表达倾向**：[只在材料足够时作情境描述] —— 论据
**说法与行动**：[自我描述是否得到具体行为支持；最终更服务谁的利益]
```
